# 贡献者

发展的每一位贡献者与上游项目。感谢所有贡献代码、文档、测试、想法与反馈的人。

## 贡献者

VisionFlow-PX4 在 **WindyLab** 课题组内开发。感谢每一位通过科研、工程与代码评审
参与并塑造本项目的组内成员与外部贡献者。

希望在此看到你的名字？请阅读[贡献指南](development/contributing.md)开始参与。
完整且实时更新的代码作者列表始终可在
[GitHub 贡献者页面](https://github.com/Renwang-Huang/VisionFlow-PX4/graphs/contributors)查看。

## 基于以下项目

VisionFlow-PX4 站在开源社区的肩膀上，离不开这些上游项目：

- [PX4 Autopilot](https://github.com/PX4/PX4-Autopilot) — 本项目 fork 自的飞控栈。
- [ROS 2 Humble](https://docs.ros.org/en/humble/)、[Gazebo Harmonic](https://gazebosim.org/)、
  [MAVLink](https://mavlink.io/) 以及更广泛的 PX4 生态。
