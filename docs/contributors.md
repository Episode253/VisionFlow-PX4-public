# Contributors

VisionFlow-PX4 is an open, community-driven effort. This page recognizes the
people and projects that make it possible. Thank you to everyone who has
contributed code, documentation, testing, ideas, or feedback.

## Maintainer

- **Renwang Huang** — <RenwangHuangX@gmail.com> ([GitHub](https://github.com/Renwang-Huang))
  Project lead and maintainer.

## Contributors

VisionFlow-PX4 is developed within the **WindyLab** research group. We are
grateful to every group member and external contributor who has helped shape
the project through research, engineering, and review.

Want to see your name here? See the [Contributing Guide](development/contributing.md)
to get started. The full, up-to-date list of code authors is always available
on the [GitHub contributors page](https://github.com/Renwang-Huang/VisionFlow-PX4/graphs/contributors).

## Built On

VisionFlow-PX4 stands on the shoulders of the open-source community and would
not exist without these upstream projects:

- [PX4 Autopilot](https://github.com/PX4/PX4-Autopilot) — the flight control
  stack this project is forked from.
- [ROS 2 Humble](https://docs.ros.org/en/humble/), [Gazebo Harmonic](https://gazebosim.org/),
  [MAVLink](https://mavlink.io/), and the wider PX4 ecosystem.

## How to Contribute

Contributions of all kinds are welcome — code, documentation, bug reports, and
suggestions. Start with the [Contributing Guide](development/contributing.md).
